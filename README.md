#Developed an Interactive Tic-Tac-Toe Game:

Utilized HTML, CSS, and JavaScript to create a fully functional Tic-Tac-Toe game with dynamic board size configuration.
Implemented responsive design principles to ensure the game is playable on various screen sizes and devices.

Implemented Customizable Game Settings:

Integrated input fields to allow users to customize board size and player symbols, enhancing user experience and engagement.
Added functionality to reset the game and scores, providing a seamless and intuitive user interface.

Enhanced User Feedback and Experience:

Created a message container to display game results and congratulate winners, improving user interaction and satisfaction.
Implemented a scoring system to track and display the number of wins for each player, adding a competitive element to the game.
